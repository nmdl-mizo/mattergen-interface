# Contributing

This repository is research code that accompanies a paper (see `README.md` and `CITATION.cff`). It is
provided so that the results can be inspected and reproduced; it is not an actively developed software package.

Issues are welcome (questions about reproduction, bug reports, errors in the documentation) at
[nmdl-mizo/symmetry-constrained-mattergen](https://github.com/nmdl-mizo/symmetry-constrained-mattergen).
Pull requests are accepted only in a limited way: small fixes that keep the released results reproducible are
welcome, while larger changes or new features are better made in a fork.

By submitting a contribution, you agree that it is your own work (or that you have the right
to submit it) and that it will be released under the [MIT License](LICENSE) of this repository.
No Contributor License Agreement (CLA) is required.

Note that this repository is not affiliated with Microsoft; the contribution process of the
upstream [microsoft/mattergen](https://github.com/microsoft/mattergen/blob/main/CONTRIBUTING.md)
repository (including the Microsoft CLA) does not apply here.
